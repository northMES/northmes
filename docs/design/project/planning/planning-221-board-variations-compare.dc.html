ARecommendation: A, docked inspector, with C's pinned Not placed row

A keeps 9 machine rows in view at 1440 by 900, C 8 and B 4. Over C, A keeps the board in view during review (no modal), does not reflow the grid when details open and close, shows the soft lock warning on every tab and has the simpler focus model. With details open and the side slot hidden, A keeps 638 px at 1280 and C 598 px; the gap is the drawn panel width, 320 against 360. A's weak point, job orders without a place behind a link to the table view, is fixed by taking C's pinned Not placed row, which keeps them one arrow key above the machines and costs one machine row of height. The spec page takes A's zoom control, a Toggle Group of the four presets with Earlier, Now, Later and Go to date, and full-width group bands as in A and C. Two changes come with it: a control that collapses the column to recover C's full-width board, and a rule for 1280 with the assistant docked, where A's grid keeps about 278 px. B's table stays as the table view and the SP3 fallback, but as the main layout it shows 4 machine rows. The side slot as a tab needs a yes against D2.
