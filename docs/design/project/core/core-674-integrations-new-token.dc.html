New integration token

An integration token lets one system, such as an ERP or a script, call the REST API as itself. You see the token once, after you create it.

Fix 2 fields to create the token
Token name, Roles

Enter a name of 1 to 80 characters.

Name the system that uses it, so others know what revoking it stops.

The token belongs to this company and never reaches another. The list holds the companies where you manage integrations.
