Access management and the no-access states: variations

Issue #304 asks for a variations round before the spec page, because the role editor and the assignment screen are new kinds of screens. This page draws three whole options in the D2 shell at Plant A: A by person, B by plant and C by role. Each shows its role editor, its assignment screen and a user's access at 1440 in light, plus one dark frame and a 320 sketch, and the frame group N draws the no-access states the way each option shows them. The user list and form, empty, loading and error states, 1280 and 1920, long strings, keyboard and focus follow the canonical list and form page (option A, pages) and come with the spec page core/core-304-access.dc.html.
