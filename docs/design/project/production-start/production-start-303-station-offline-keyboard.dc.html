Reload when idle

After an update, the station reloads by itself only when all three hold:

  1. Nobody uses it: no input and no command in flight.
  2. No form holds unsent input: no typed entries and no entries kept for an operator who was signed out.
  3. The module versions changed: the build in the response header, or the module list after a reconnect, differs from the station's.

Here nobody is signed in and nothing is kept, so the station reloaded and shows its sign-in screen again. The Badge field takes focus through its ref, as on every load. Nothing is announced.

When it waits

  • Typed entries: no reload. Send is refused with core.client_outdated and offers Reload; the entries stay (OF12, OF13).
  • Entries kept for a signed-out operator: no reload until that operator sends them (OF6, OF11, question OFQ2).
  • Queries still pass on the old build; only mutations are refused.

What counts as idle, and whether a signed-in operator stays signed in across the reload, is question OFQ3.
