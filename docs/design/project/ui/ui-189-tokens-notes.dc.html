Build notes, not part of the UI

These notes are for the implementer of E04-S01. They are not a screen and are not drawn in the product. They become docs/design/ui/ui-189-tokens.md with the approved etags of all 13 files.

Token names and values

84 color tokens in :root (light) and .dark, plus 6 shared values. Source: tokens.css in this project; the values are not in a repository commit yet. oklch is the source value and hex its sRGB rendering.

Contrast ratio of each pair

The 275 required pairs, light and dark side by side, rounded down. Pre-test values until packages/ui/test/tokens.contrast.test.ts exists, which asserts "every text pair meets 4.5:1 in light and dark" and "the focus ring meets 3:1 on every surface".

The focus ring on every surface

:focus-visible {
  outline: 2px solid var(--focus-outline);
  outline-offset: 2px;
  box-shadow: 0 0 0 2px var(--focus-ring);
}

It replaces shadcn's outline-ring/50 in the base layer. ring and sidebar-ring hold the focus-outline value for components that read them, without the /50. The outline survives forced-colors mode.
