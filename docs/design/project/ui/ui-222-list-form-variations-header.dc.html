Canonical list and form page: variations

Three ways to arrange the list, the detail and the form of a master data screen, drawn on the articles of Acme AB inside the approved D2 shell with the D1 tokens and components. Articles are not a register: core declares their routes with screenRoute and uses the command forms directly, and a register such as tools gets the same four routes from masterDataRoutes. Krister picks one option, or names the parts to combine. The spec page ui-222-list-form.dc.html then draws every frame of issue #222 in light and dark, at 1280, 1440, 1920 and 320 px.
