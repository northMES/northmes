Five look-and-feel directions

A variations round to choose the base for D1. It explores direction only and does not set the final tokens. Each direction page shows the same invented content: palette and contrast pairs, type, controls in every state, a planning board slice, a list page and an operator station at 1280 by 800, in a light and a dark theme. Each page computes its ratios from its own hex values, and every required pair passes WCAG 2.2 AA.

  • The project is bound to the Broadsheet design system. These pages define their own CSS variables and do not load its stylesheet.
  • Fonts load from Google Fonts on these pages. The app self-hosts its fonts and makes no CDN calls.
  • Icons are Lucide shapes, the set @northmes/ui uses.

Choices before D1 continues

  1. Which direction continues as the D1 base, or which parts to combine, for example one palette with another font.
  2. The font: IBM Plex Sans, Atkinson Hyperlegible Next, Source Sans 3 with Source Serif 4, Archivo, or the system stack. Greek and Cyrillic coverage differs between them.
  3. Light first or dark first, and whether the station layout gets its own default theme.
  4. Keep or remove the Broadsheet binding on this project, or move D1 to a new project.
  5. The block border in dark themes. The plan names the background token, which measures about 1.0:1 against the lane on every page here, so each page uses a light block border token instead.
