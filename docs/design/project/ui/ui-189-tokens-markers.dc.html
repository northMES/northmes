Focus ring geometry (06 Color and contrast, Q2)

  • Inner band, 2 px, against the control edge: focus-ring, the background value ({{ ringHex }}). Drawn with box-shadow: 0 0 0 2px var(--focus-ring).
  • Outer band, 2 px, against the surface: focus-outline, the foreground value ({{ outlineHex }}). Drawn with outline: 2px solid var(--focus-outline); outline-offset: 2px, so forced-colors mode keeps it.
  • The halves are {{ apart }}:1 apart, more than the 9:1 of WCAG technique C40, so one half reaches 3:1 on any color. Over all 16,777,216 sRGB colors the weakest result is {{ worst }}:1 (fill {{ worstHex }}).
  • It replaces shadcn's outline-ring/50 (1.54:1 light, 1.87:1 dark). shadcn components take the ring from @northmes/ui, never the /50 opacity.
  • Focus only shows the ring and scrolls the element into view. Selection is separate (aria-selected).
