What differs between the themes

{{ d.k }}{{ d.v }}

Rules

  • Every screen defaults to the light theme, stations included. Each user or station can switch to dark.
  • The choice is stored per browser in localStorage under one key and applied by the shell entry before the first render. It is not a setting and is not audited. A station keeps its choice per device.
  • Tokens sit in :root for light and .dark for dark. theme.css in @northmes/ui maps them with @theme inline and holds no values.
  • Every frame on this page exists in both themes, side by side.
