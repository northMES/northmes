Keyboard and focus

Tab order, keys and where focus goes after each action, for the D1 components. The docs set the rules marked with a source; keys for the standard composites follow the WAI-ARIA Authoring Practices and Base UI defaults until Q11 is settled. Every focus stop draws the two-tone ring, except menu and listbox items, which draw a 2 px inset outline in focus-outline (P4). Keyboard-only end-to-end flows run without page.mouse.
