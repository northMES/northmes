Fonts and icons

IBM Plex Sans sets interface text and IBM Plex Mono sets numbers, always with tabular figures. Both are under the SIL Open Font License and are self-hosted and bundled in the product, which makes no CDN calls. Sizes are in rem, so 200 percent text zoom grows rows and text containers; only board blocks keep a fixed height. theme.css maps the families to font-sans and font-mono.
