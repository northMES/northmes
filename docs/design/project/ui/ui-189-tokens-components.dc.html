shadcn components in every state

Names are shadcn component names; @northmes/ui wraps them (Button also serves IconButton). Hover, focus-visible and active are drawn as fixed states; the real buttons on this page also respond to the pointer and the keyboard. Controls are 36 px tall and every target is at least 24 by 24 px. A dash in the spec's state matrix means the state does not apply, so it is not drawn.

Button

{{ h }} {{ b.v }}

Variant names are shadcn's. Primary hover uses primary-hover. Outline and ghost hover use accent; outline also darkens its border to foreground. Secondary hovers with shadcn's 80 percent opacity, which is not a token (P2). Destructive keeps Graphite's outlined look: destructive text and border on card, and destructive-subtle on hover. Active is the hover color plus a 1 px press, with no token of its own. Disabled is 50 percent opacity (Q8). Loading (Q8, proposal) keeps full opacity, swaps in a progress label with LoaderCircle and sets aria-busy and aria-disabled. Buttons have no invalid state.

Checkbox with its 24 px hit area (dashed)

{{ c.h }}

The shadcn checkbox box is 16 px. Its hit area is var(--nm-target-min), 24 px by default and 44 px in the station layout, and the label is part of the target. Checked and indeterminate use the primary fill. Indeterminate (Q8, proposal) shows Minus and sets aria-checked="mixed". Invalid adds the destructive border and inset.
