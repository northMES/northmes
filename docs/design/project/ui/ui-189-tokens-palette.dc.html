Block text rule for any color

Order colors are not limited to the palette: the ERP sends ColorCode as #RRGGBB and a planner can pick any color. textColorFor(fill) in @northmes/contracts returns pure black or pure white, whichever contrasts more, and reaches at least 4.58:1 on every one of the 16,777,216 sRGB colors. The fills below are invented examples; #cf0dcc is the worst case. One imported hex is drawn the same in both themes until Q9 settles a dark rule.

Rules

  • Color groups and never carries state; no state maps to a hue at any density.
  • On the board the fill is always the order color, in every state.
  • Board block colors are a CSS variable, not a class per color; dynamic class names are banned.
  • Palette classes go through @source inline() for the swatch components.
  • Only the color swatch components use forced-color-adjust: none; a CI grep fails any other use.
  • ColorSwatchPicker offers the 20 palette colors plus any color, with text from textColorFor.
  • The value type is paletteColor in @northmes/contracts.
  • Palette values differ per theme (dark is light lightness minus 0.08). The ERP sends one hex (Q9).
