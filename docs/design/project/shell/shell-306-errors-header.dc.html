Error and system pages (E04-S02-T02)

What NorthMES shows when a link cannot be read, a page or a record is not found, the server fails or cannot be reached, NorthMES is down for an upgrade, the session ends, the shell boots or cannot start, and the browser is too old or not on HTTPS. The pages inside the shell mount shell/Shell.dc.html read only; D2's module page not found (ST5), error panel (ST6) and unknown plant (ST29) are the reference and are not drawn again.
