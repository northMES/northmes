Frame F0

Dashboard with shared and personal tabs: variations

Issue #454 asks for a variations round before the spec page, because the dashboard is the landing page and its layout model is new. Krister Johansson answered the issue's questions on 2026-10-10: shared tabs exist at the company and at the plant, and the role that may change them is decided later; a user's own tabs follow the user to every plant; release 1 ships four demo widget types, List, Table, Value and Chart, each with its own settings. This page draws three whole options that differ in the tab control and the edit model: A, tabs and edit mode; B, side column; C, tab picker and tiles. Each option draws nine frames: the shared tab, the catalog, one widget's settings beside a second copy, the shared tab for someone who may change it, the own tab at another plant with the widget states, the empty own tab, a move without dragging and two 320 frames. Frame G holds the grid library, the widget sizes in grid units and draft build notes. The rest of the issue's frame list (1920, long strings, the full keyboard and focus frames, every tab management dialog) follows on the spec page for the chosen option.
