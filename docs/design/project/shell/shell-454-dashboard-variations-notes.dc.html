Breakpoints

Measured on the grid container (useContainerWidth), not on the viewport, because the 256 px sidebar, the 64 px rail and docked panels change the room. The widths are the drawn ones: 24 px page padding on each side and the frames' 1 px screen border, so a browser window gives 2 px more. lg starts at 900 px, so 1280 keeps 12 columns when a permanent vertical scrollbar (17 px with Windows classic scrollbars, or macOS set to always show them) takes the grid to 957 px. rowHeight 72 px, margin [16, 16], containerPadding [0, 0]: a widget h rows tall is 72h + 16(h - 1) px, so 2 rows are 160 px, 4 rows 336 px and 6 rows 512 px.

Widths are rounded to whole pixels, as react-grid-layout rounds them. At 6 columns a half-width widget is 292 px wide in a 600 px container and 442 px in an 899 px one. At one column the heights are minimums, and content can make a widget taller; a Table scrolls sideways in its own region, as plan 06 allows for data tables.
